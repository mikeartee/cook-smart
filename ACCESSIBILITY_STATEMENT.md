# Accessibility Statement - Cook Smart

**Effective Date**: [To be set at launch]  
**Last Updated**: November 13, 2025

## 1. Our Commitment

Cook Smart is committed to ensuring digital accessibility for all users, including those with disabilities.

## 2. Standards

We aim to conform to WCAG 2.1 Level AA standards.

## 3. Features

### 3.1 Visual
- High contrast support
- Scalable text (up to 200%)
- 4.5:1 contrast ratio minimum
- Color-independent information

### 3.2 Navigation
- Full keyboard navigation
- Clear focus indicators
- Skip links
- Logical tab order

### 3.3 Screen Readers
- Semantic HTML
- Alt text for images
- ARIA labels
- Clear form labels

### 3.4 Mobile
- 44x44px touch targets
- Gesture alternatives
- Portrait/landscape support
- Zoom support

## 4. Assistive Technologies

Compatible with JAWS, NVDA, VoiceOver, TalkBack, and other assistive technologies.

## 5. Known Limitations

- Some recipe images may lack detailed alt text (BETA)
- Barcode scanning has limited screen reader support
- Some third-party content may not meet standards

## 6. Feedback

Report accessibility issues to: tootallgames2020@gmail.com

Include:
- Description of issue
- Page/feature affected
- Assistive technology used
- Browser and device info

Response time: 5 business days

## 7. Ongoing Efforts

- Regular accessibility testing
- Automated and manual testing
- User testing with people with disabilities
- Team training on accessibility

## 8. Compliance Status

Partially conformant with WCAG 2.1 Level AA. Some content does not fully conform.
