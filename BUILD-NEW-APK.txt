# The app is not loading the new code

## The Problem
You've uninstalled and reinstalled but the app still shows old screens.
This means you're installing an OLD APK that doesn't have the navigation changes.

## Solution: Build a NEW APK

### Option 1: Using build-apk.ps1 (if it exists)
```powershell
.\build-apk.ps1
```

### Option 2: Manual build
```bash
cd android
gradlew clean
gradlew assembleRelease
```

### Option 3: React Native CLI
```bash
npx react-native run-android --variant=release
```

## After Building
1. Find the new APK at: android/app/build/outputs/apk/release/app-release.apk
2. Install it on your device
3. Test the buttons

## Why This Happened
- Metro bundler only hot-reloads JavaScript changes
- Navigation structure changes require a full rebuild
- Uninstalling doesn't help if you reinstall the same old APK
- You need to build a NEW APK with the new navigation code

## Quick Test
After installing the new APK, tap "Data Usage Policy" - you should see "TEST SCREEN WORKS!"
If you do, then navigation is working and we just need to put the real screens back.
