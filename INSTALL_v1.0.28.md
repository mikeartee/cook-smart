# Install Cook Smart v1.0.28 - Password Reset Feature

## APK Location
**Desktop:** `CookSmart-v1.0.28-password-reset.apk` (94.87 MB)

## What's New in v1.0.28
- 🔐 Forgot Password feature
- 📧 Email-based password reset
- 🔢 6-digit verification codes
- ⚡ Fast email delivery (10-30 seconds)

## Installation Steps

### 1. Transfer to Phone
- Connect phone via USB
- Copy APK to phone's Downloads folder
- Or use Google Drive/email to transfer

### 2. Install APK
1. Open file manager on phone
2. Navigate to Downloads
3. Tap `CookSmart-v1.0.28-password-reset.apk`
4. If prompted, enable "Install from Unknown Sources"
5. Tap "Install"
6. Wait for installation to complete
7. Tap "Open"

## Test Password Reset

### Step 1: Request Reset
1. Open Cook Smart app
2. Tap "Forgot Password?" on login screen
3. Enter your email address
4. Tap "Send Verification Code"

### Step 2: Check Email
1. Open your email inbox
2. Look for email from "Cook Smart <noreply@cooksmartapp.com>"
3. Subject: "Reset Your Cook Smart Password"
4. Copy the 6-digit code

### Step 3: Reset Password
1. Return to Cook Smart app
2. Enter the 6-digit code
3. Enter your new password (min 8 characters)
4. Confirm new password
5. Tap "Reset Password"

### Step 4: Login
1. You'll be redirected to login screen
2. Enter your email
3. Enter your NEW password
4. Tap "Sign In"

## Troubleshooting

### Email Not Received?
- Check spam/junk folder
- Wait 30 seconds for delivery
- Verify email address is correct
- Try again with "Resend Code"

### Code Invalid?
- Codes expire after 1 hour
- Each code can only be used once
- Request a new code if expired

### Installation Blocked?
- Go to Settings > Security
- Enable "Install from Unknown Sources"
- Or "Allow from this source"
